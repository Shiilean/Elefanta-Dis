Base de datos (Excel / CSV)

Descargar la base de datos actual

Descarga el catálogo del programa al día (con el stock y precios actuales) como Excel. Úsalo para respaldar, editar en masa o enviárselo a una vendedora o administrador. Luego vuelves a importarlo.

Importar / carga masiva

Sube un archivo .xlsx o .csv con una fila por producto. La primera fila debe tener los títulos de columna. Se reconocen estas columnas (el orden no importa, mayúsculas/acentos dan igual):

nombre, sku, precio (o "precio de venta"), stock, categoria, tienda, coste (costo sin IVA), costo con iva, comision (opcional), tipo (opcional).

Si una tienda o categoría no existe, se crea sola. La comisión, si viene vacía, se pone en 0% para Elefanta y 10% para las demás tiendas. Al confirmar podrás elegir entre reemplazar los valores del catálogo o agregar todo como nuevo.

Partir desde cero

Borra todo en todos los dispositivos: productos, papelera, ventas y compras, y deja las tiendas y categorías en limpio (solo Elefanta). Úsalo para dejar el programa como recién instalado antes de cargar tu inventario real. Esta acción no se puede deshacer.

"Reiniciar ventas y compras" deja los productos y el stock como están, y borra el historial de ventas y compras (las tablas de ventas vuelven a cero). Útil para empezar a operar en limpio.
